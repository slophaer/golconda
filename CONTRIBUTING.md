# Contributing

1. Use kernel commit style: `area: summary` (lower case, imperative,
   50 characters or fewer, no period), a blank line, then a body that
   explains what and why, wrapped at 72 columns. Sign off with
   `git commit -s`.
2. One commit per feature. Each commit must leave the tree evaluating.
3. Work on a feature branch in a git worktree. Do not commit to main.
