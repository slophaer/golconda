of a run alone, plus `imds-import-inactive`
([Image artifacts: the boot test](reference/image.md#boot-test-scriptsboot-test)).

- the clock: each first boot started at 1980-01-01, the build epoch, until timesyncd synced. Now
  systemd's `time-epoch` is the pin's date (`clock-not-reset`).

| two builds of the initrd from the same inputs give the same bytes        | `packages.x86_64-linux.initrd-reproducible`, which `scripts/verify` builds: the test image's initrd and a second build of its derivation (one unread variable more, the first build's output, so it starts after the first ends) are compared byte for byte. Not proven: two builds on hosts with different build file systems. `gen_init_cpio` takes only the
names, modes, link targets and contents from the build directory and writes fixed inode, device and
link-count fields, but no test builds on a second file system. A whole release built twice from the
same inputs is not compared either.

## Not proven

- **Enrolment on real firmware.** The harness enrols keys offline in the variable store. Hetzner
  Cloud has no Secure Boot.

- **Hardware.** Only QEMU with OVMF on x86_64 has run, and Hetzner Cloud's QEMU with EDK II. aarch64
  is postponed ([Scope: Later](design/scope.md#later)), because no aarch64 package can be built
  here.

- **Loader recovery by hand.** A loader that no longer starts, a lost ESP and a lost `db` key
  ([Boot loader: Recovery](design/bootloader.md#recovery)) have no marker. The rotation run has two
  releases, so it leaves out step 4 of the rotation.

- **A boot without the `db` enrolled.** It stops at switch-root; the harness has no marker for it.

- **A key on a token.** The signer reads a key directory and refuses a PKCS#11 URI *(later)*.
